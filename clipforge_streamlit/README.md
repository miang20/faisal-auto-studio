# ClipForge Streamlit Studio

Streamlit prototype for editing rights-cleared source videos with FFmpeg and optionally finding licensed B-roll from Wikimedia Commons. Requires ffmpeg and ffprobe. Deploy Streamlit Community Cloud with main file `clipforge_streamlit/app.py`. This is a free-first experimental CPU renderer; hosting can terminate long jobs and is not guaranteed for 8-10 minute videos. Semantic scene recognition and continuous scheduled indexing are not implemented. Check media rights before publication.
